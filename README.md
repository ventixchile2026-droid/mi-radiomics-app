# mi-radiomics-app

Aplicación Streamlit para cargar y previsualizar imágenes; plantilla para integrar extracción de features radiomics.

## Requisitos

- Python 3.8+
- virtualenv

## Instalación

1. Clona el repositorio:
   git clone git@github.com:ventixchile2026-droid/mi-radiomics-app.git
   cd mi-radiomics-app

2. Crear un entorno virtual e instalar dependencias:
   python3 -m venv venv
   source venv/bin/activate   # Windows: .\venv\Scripts\activate
   pip install -r Requirements.txt

## Uso

- Ejecutar la app:
   streamlit run app.py
- Abrir la URL que Streamlit muestre (usualmente http://localhost:8501)
